To open the web project, use the project root folder (one level above this folder) and run:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Demo.ps1 -OpenBrowser

The web app URL is http://127.0.0.1:8081. Demo accounts admin, trainer, and user1 use password 123.
The full project package remains at output\Gym_Web_STQA_Submission.zip.
